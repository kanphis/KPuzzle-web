# KPuzzle

Six classic logic puzzles in one app — **Sudoku, Hitori, Nonograms, Minesweeper, Nurikabe, and Kakuro** — built with Kotlin Multiplatform and Compose, running on Android, iOS, desktop, and the web.

**Play in the browser:** https://kanphis.github.io/KPuzzle-web/

## About this repository

This repository hosts the **prebuilt web bundle only** and is updated whenever a new production build is published. The application source code is private.

The third-party open-source libraries used by the app are listed with their full license texts in the app itself, under **Settings → More → Open-source licenses**.
